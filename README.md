# ۱۶۳۲ سوال

یه صفحه‌ی وب ساده که هر بار لمسش کنی، یکی از سوال‌های داخل فایل `1632.json` رو به‌صورت تصادفی نشون می‌ده؛ با یه پس‌زمینه‌ی کهکشانی و انیمیشن حرکت به سمت جلو (warp) موقع رد شدن به سوال بعدی.

## فایل‌ها

| فایل | کاربرد |
|---|---|
| `index.html` | خود صفحه‌ی سایت. کهکشان، انیمیشن، و منطق نمایش سوال تصادفی همه اینجاست. |
| `1632.json` | آرایه‌ای از رشته‌ها (سوال‌ها). این فایلیه که سایت هر بار می‌خونه. |
| `convert.py` | اسکریپت پایتون برای ساختن `1632.json` از روی یه متن ساده، بدون نگرانی بابت فرمت JSON. |

## چطور کار می‌کنه

- `index.html` هنگام باز شدن، فایل `1632.json` رو با `fetch` می‌خونه (بدون کش، همیشه آخرین نسخه).
- لمس هر جای صفحه یه انیمیشن warp اجرا می‌کنه و بعدش یه سوال تصادفی از آرایه نشون می‌ده.
- روی صفحه هیچ متن دیگه‌ای جز خود سوال نیست.

## اضافه یا ویرایش سوال‌ها

دو راه داری:

**۱. مستقیم ویرایش `1632.json`**
فایل باید همیشه یه آرایه‌ی معتبر JSON از رشته‌ها باشه:
```json
[
  "سوال اول؟",
  "سوال دوم؟"
]
```
⚠️ بین هر دو جمله حتماً کاما (`,`) بذار، وگرنه فایل نامعتبر می‌شه و سایت نمی‌تونه بخونتش.

**۲. با `convert.py` (پیشنهادی، بدون دردسر فرمت)**
یه فایل متنی بساز که هر خطش یه سوال باشه، بعد:
```bash
python convert.py input.txt
```
یا بدون فایل، مستقیم اجرا کن و متن رو پیست کن:
```bash
python convert.py
```
اسکریپت خودش `1632.json` رو با فرمت درست کنار خودش می‌سازه.

## اجرا روی سیستم خودت

فقط کافیه `index.html` رو با یه سرور محلی ساده باز کنی (باز کردن مستقیم فایل با دابل‌کلیک ممکنه به‌خاطر محدودیت مرورگرها در خوندن فایل لوکال با `fetch` کار نکنه):

```bash
python -m http.server 8000
```
بعد برو به `http://localhost:8000`.

## دیپلوی روی GitHub Pages

1. هر سه فایل (`index.html`، `1632.json`، `convert.py`) رو توی ریشه‌ی ریپازیتوری بذار.
2. از تنظیمات ریپو، بخش **Pages** رو فعال کن و شاخه‌ی `main` رو انتخاب کن.
3. سایت روی آدرس `https://<username>.github.io/<repo-name>/` بالا میاد.

## نکته درباره‌ی کش

اگه بعد از ویرایش `1632.json` هنوز سوال‌های قدیمی رو می‌بینی، یه Hard Refresh بزن (`Ctrl+Shift+R` یا `Cmd+Shift+R`)؛ خود کد هم با پارامتر ضدکش نوشته شده تا این مشکل کمتر پیش بیاد.
